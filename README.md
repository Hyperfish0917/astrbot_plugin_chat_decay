# AstrBot 群聊唤醒与对话衰减插件

为 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 的 QQ 群聊提供「偶尔插话、逐轮变少、及时冷却」的轻量插件，目的是减少无意义的 LLM 调用和群聊刷屏。

**版本**：1.3.0 · **适配**：AstrBot ≥ v4.29.3，主要面向 OneBot v11（例如 SnowLuma） · **许可**：[MIT](LICENSE)

## 能做什么？

- **直接唤醒**：群成员 @ 机器人、引用机器人、AstrBot 原生唤醒前缀，或文本包含配置关键词，立即允许默认 LLM 回复；直接唤醒不受冷却限制。支持英文忽略大小写；QQ 戳一戳在事件含目标 ID 且目标为机器人时也可唤醒。
- **冷启动插话**：没有活跃话题时，普通群消息以默认 **20%** 的概率唤醒。
- **三轮跟进**：首次唤醒后，后续普通消息依次以 **100% → 80% → 50%** 的概率继续；每次成功才前进一轮，抽签未中不会扣轮次，最后一轮成功后进入冷却。
- **强制冷却**：默认 **90 秒**，期间不再随机插嘴，但 @、关键词仍可打断冷却。
- **话题超时**：默认 **30 秒**没有成功触发，新消息重新使用冷启动概率。
- **多群独立**：不同群、不同平台实例、不同机器人分别计时。
- **管理按钮**：在插件详情页打开「恢复默认设置」View，支持只恢复四项概率，或恢复全部默认配置。

## 安装与更新

1. 在 AstrBot WebUI 进入「扩展功能 → 插件 → 安装插件」，选择 **从 GitHub 仓库链接安装**。
2. 填写 `https://github.com/Hyperfish0917/astrbot_plugin_chat_decay`，安装并启用。
3. 进入插件配置，填写关键词和概率，保存。如使用自定义唤醒词，正常文字命中即可，无需在 AstrBot 的系统唤醒词里重复设置。
4. 在插件详情页可打开「恢复默认设置」View 使用两个重置按钮。更新后若未显示，请重载插件并刷新页面。

也可下载本仓库源代码 ZIP，按 AstrBot 的「从文件安装」流程导入。

## 配置

**v1.3.0 默认值调整：**冷启动 20%、第 1/2/3 轮跟进 100%/80%/50%、冷却 90 秒、话题超时 30 秒；最大轮数仍为 3，关键词及忽略大小写保持不变。升级已有安装时，AstrBot 可能继续保留你保存过的旧配置；如需套用新默认值，请在插件详情页的 View 中点击「恢复全部默认设置」，或在配置界面逐项调整。

| 配置项 | 默认 | 说明 |
|---|---|---|
| `keywords` | `肥鱼, 鲸鱼, deepseek` | 消息文本包含任一词即强制唤醒；**请修改成你的机器人唤醒词** |
| `ignore_case` | true | 英文大小写不敏感 |
| `base_passive_rate` | 0.2 | 冷启动随机插话概率，取 0～1 |
| `decay_rate_1` | 1.0 | 第 1 轮跟进概率 |
| `decay_rate_2` | 0.8 | 第 2 轮跟进概率 |
| `decay_rate_3` | 0.5 | 第 3 轮跟进概率 |
| `max_turns` | 3 | 最大成功跟进次数，取 1～3 |
| `cooldown_seconds` | 90 | 冷却秒数，0～3600 |
| `session_timeout_seconds` | 30 | 超时重置秒数，1～3600 |

异常概率值会回退到默认值；过大的时长与轮数会在运行时安全截断。配置编辑后即可影响下一次消息；内存中的话题状态在插件重载时会清空。重置按钮也会清空话题状态。

**例子**：群友说「肥鱼在吗」→ 直接唤醒 → 下一条普通消息有 100% 概率跟进 → 成功后下条为 80% → 成功后下条为 50% → 第三次跟进成功后冷却 90 秒。一次没有抽中，可以在 30 秒内等待下一条继续抽本轮概率；30 秒内都没有成功则退回 20%。

## 兼容和限制

- 插件只处理群聊的**默认 LLM 唤醒**，不会阻止其他插件自己的 LLM 调用或自带指令，不会修改系统的全局唤醒配置。
- 此插件使用 AstrBot `event.is_at_or_wake_command` 激活默认 LLM；请避免与其他会自动触发大模型的插件重复启用，以免重复调用或触发冲突。
- 触发概率不等于大模型最终会回复的保证：AstrBot 的访问控制、会话配置、LLM 服务失败以及其他插件仍可能阻止回复。
- 对 QQ 戳一戳的支持取决于消息适配器提供的 Poke 消息段及目标 ID；未提供目标 ID 的事件不会被当成强制唤醒。
- **未经真实 QQ 群环境验收，不声称已通过端到端真机测试**。参见测试说明。

## 开发与测试

仅测试概率状态机及 AstrBot API 的模拟环境行为：

```bash
python -m pytest -q
```

该测试不调用 QQ 或 LLM API，也不需要 API Key。首次使用请在实际 AstrBot v4.29.3 + OneBot v11 群聊中确认是否存在其他插件的冲突。

## 安全与隐私

无外部依赖、无主动网络请求、无消息归档与遥测；仅在内存中保存会话状态。仓库不包含用户 QQ ID、群号、访问令牌、设备地址或凭据。插件的两个重置接口通过 AstrBot WebUI 的认证机制访问。
